# 🏋️‍♂️ WorkoutBuddy — MERN Fitness Tracker App

A full-featured **Workout Tracking Application** built using the **MERN stack** (MongoDB, Express, React, Node.js).  
Users can **create, read, update, and delete workout records** securely with **JWT authentication**.

---

## 🚀 Live Demo
🔗 **Client Website:** https://workout-client-sandy.vercel.app/  
🔗 **Backend API:** https://workout-server-ptc4.onrender.com

---

## 📌 Features

- User **Signup / Login** with JWT authentication
- Add, update, delete workout records
- View workouts specific to the logged-in user
- MongoDB Atlas cloud database
- Responsive UI with Tailwind CSS
- Secured backend API with middleware
- Deployed on **Vercel** (frontend) & **Render** (backend)

---

## 🧰 Tech Stack

| Layer | Technology |
|--------|------------|
| Frontend | React, Tailwind CSS, Axios |
| Backend | Node.js, Express.js |
| Database | MongoDB Atlas |
| Authentication | JSON Web Token (JWT) |
| Deployment | Vercel (client), Render (server) |
